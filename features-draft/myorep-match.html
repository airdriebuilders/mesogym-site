Myorep Match Sets

A myorep match set keeps the weight from your first set and uses short mini-sets until your total matches its reps. Meso Gym does the remembering for you.

Know Exactly What a Match Set Is

Not sure how it works? Tap the ? on Myorep Match for a short explainer right on the workout screen: same weight as set 1, mini-sets with 3–5 breath pauses, until your total matches set 1's reps.

The Number to Hit, Right in the Box

Available from the second set on. The reps box shows a blue Match strip with your first set's reps, so there's nothing to remember. Got a different total? Type it and tick: what you did is what's saved.

Turn a Short Set Into a Match

If a heavy set comes up short, convert it to Myorep Match from the prompt under the row. You keep the weight, the set is tagged MATCH, and you finish the reps with mini-sets.

Like every set type, it counts as one set for weekly volume and stays out of your strength numbers.

Related Features

  • Myorep Sets: Mini-sets after a near-failure set, with the target reps shown.
  • Drop Sets: Pick your drops, pre-filled lighter, each with its own tick.
  • The Live Workout Screen: Log sets against an RIR target, rest, swap and flag joint pain.
